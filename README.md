# goodfaith-demo-titlecase

This is a demo repository for [Goodfaith](https://goodfaith.onrender.com), not a real project. It shows trust travelling between projects: a pull request merged through Goodfaith at one of the two sibling demos, [truncate](https://github.com/leejpsd/goodfaith-demo-truncate) and [titlecase](https://github.com/leejpsd/goodfaith-demo-titlecase), lets the same person skip the gate at the other. All money involved is PayPal sandbox money.

The code is one small function. It capitalises the first letter of each word.
